🧮 Human Age Calculator

A clean and responsive web app that calculates your exact age in years, months, and days based on your date of birth. Built using HTML, CSS, and vanilla JavaScript.
✨ Features

    Enter your birth date and get your current age in detail

    Stylish gradient UI with modern layout

    Fully responsive and mobile-friendly

    Prevents future date selection with dynamic input restriction

    Simple and lightweight — no libraries or frameworks used

💻 Technologies Used

    HTML5

    CSS3 (with linear gradients, flexbox, and custom input styling)

    JavaScript (ES6) for age calculation logic

📁 How to Use

    Clone the repository or download the source files.

    Open index.html in your browser.

    Select your birth date using the date picker.

    Click the Calculate button to see your age broken down into years, months, and days.
